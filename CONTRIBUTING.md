# Contributing to AI Operations Community

Thank you for contributing to the public collaboration space for saulius-systems-labs.

## How to contribute

1. Read the repository purpose and context in this README.
2. Open an issue for ideas, proposals, or cross-cutting discussions.
3. Submit a pull request for documentation or community improvements.
4. Keep feedback focused on practical value, clarity, and collaboration quality.

## What we welcome

- documentation improvements
- architecture and operations notes
- learning resource suggestions
- contributor onboarding improvements
- public-facing collaboration patterns

## Contribution expectations

- be respectful and constructive
- explain the purpose and context of the change
- prefer actionable, concrete suggestions over vague discussions
- keep contributions aligned with the public mission of the organization

## Review guidance

Pull requests and issues should ideally include:
- a brief summary of the change or idea
- motivation and context
- expected benefits for the community
- any links or references that support the proposal

## Communication

Use GitHub Issues and Discussions for questions, proposals, and public feedback.
