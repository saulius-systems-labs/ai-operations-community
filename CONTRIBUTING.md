# Contributing to AI Operations Community

Thank you for contributing to the public collaboration space for saulius-systems-labs.

## How to get involved

There are several ways to participate in our community:

### 1. Join the conversation
- Read the repository purpose and context in the README
- Open an issue for ideas, proposals, or cross-cutting discussions
- Submit a pull request for documentation or community improvements
- Keep feedback focused on practical value, clarity, and collaboration quality

### 2. Explore collaboration opportunities
- Visit [WorkTravel.Agency - For Talent](https://www.worktravel.agency/for-talent) to learn about collaboration and contribution opportunities
- Subscribe to our [LinkedIn newsletter](https://www.linkedin.com/newsletters/engineering-my-ai-twin-7497215161590521856/) for updates on AI twin engineering and operations
- Check out our [YouTube channel](https://www.youtube.com/@AI-Systems-Skills-Academy) for learning resources and architecture discussions

### 3. Apply to contribute
If you're interested in contributing or collaborating with saulius-systems-labs, we encourage you to:
1. Review our [collaboration framework](https://github.com/saulius-systems-labs/collaboration-framework) and contribution expectations
2. Explore open issues and discussions in this repository
3. Apply through our talent network at [WorkTravel.Agency](https://www.worktravel.agency/for-talent) to express your interest

## What we welcome

- documentation improvements
- architecture and operations notes
- learning resource suggestions
- contributor onboarding improvements
- public-facing collaboration patterns
- ideas for better community engagement

## Contribution expectations

- be respectful and constructive
- explain the purpose and context of the change
- prefer actionable, concrete suggestions over vague discussions
- keep contributions aligned with the public mission of the organization

## Review guidance

Pull requests and issues should ideally include:
- a brief summary of the change or idea
- motivation and context
- expected benefits for the community
- any links or references that support the proposal

## Communication

Use GitHub Issues and Discussions for questions, proposals, and public feedback.
